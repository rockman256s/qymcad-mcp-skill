# Ассистент QymCAD

[English](SKILL.md) · **Русский** — перевод для людей; агент читает [`SKILL.md`](SKILL.md).

QymCAD — настольная параметрическая САПР (Rust, OpenCASCADE 7.9.3). Ветка `feat/ai-assistant`
форка `rockman256s/QymCAD` добавляет:

- **`qymcad-mcp`** — MCP-сервер (stdio) с 20 инструментами;
- **живой режим в окне QymCAD** — когда в *Настройки → Общие* стоит галочка «Разрешить ИИ-ассистенту
  работать в этом окне», каждый вызов инструмента выполняется в открытом окне как отдельный шаг:
  рисуется сразу, пишется в строке состояния и отменяется по Ctrl+Z. `screenshot` возвращает снимок
  окна (PNG), чтобы агент видел, что построил.

Если окно не слушает, сервер строит документ у себя в процессе (без окна) и умеет сохранить `.qcad`
и выгрузить STEP и STL.

Пока основной проект (`QymIs-Tech/QymCAD`) не принял эти изменения, живой режим есть только в сборке из
ветки выше — в готовых пакетах QymCAD его нет.

## 1. Установка

### Windows 10/11 x64 (проверено)

В PowerShell (скрипт ставит Git, CMake, Rust, VS 2022 Build Tools с C++, собирает OCCT 7.9.3 в
`C:\occt`, клонирует и собирает ветку, кладёт обе программы вместе с DLL OCCT в
`%LOCALAPPDATA%\Programs\QymCAD-assistant` и регистрирует MCP-сервер в Claude Code, если найдёт его CLI):

```powershell
irm https://raw.githubusercontent.com/rockman256s/qymcad-mcp-skill/main/scripts/setup-windows.ps1 -OutFile setup-windows.ps1
powershell -ExecutionPolicy Bypass -File .\setup-windows.ps1
```

Прочитайте скрипт перед запуском. Нужно ~10 ГБ на диске; установщики спросят права администратора (UAC);
OCCT собирается 20–40 минут при первом запуске, QymCAD — около 10 минут. Скрипт можно запускать повторно:
то, что уже есть, пропускается.

Подводные камни Windows (скрипт их обходит):

- **Пути длиннее 260 символов.** Клонируйте и собирайте в коротком пути (`$HOME\src\QymCAD`,
  `CARGO_TARGET_DIR` вроде `C:\qt`) и включите `git config core.longpaths true`. `Expand-Archive` на этом
  репозитории падает — используйте `git clone` или `tar`.
- **OCCT собирается из исходников**, ровно 7.9.3, с `BUILD_RELEASE_DISABLE_EXCEPTIONS=OFF` и
  `INSTALL_DIR_LAYOUT=Unix` (см. `packaging/README.md` в репозитории). Генератор:
  `-G "Visual Studio 17 2022" -A x64`.
- **Переменные сборки:** `OCCT_INCLUDE_DIR=C:\occt\include\opencascade`, `OCCT_LIB_DIR=C:\occt\lib`,
  `OCCT_ROOT=C:\occt`; при запуске DLL OCCT должны быть в `PATH` или рядом с `.exe`.

### Linux (здесь не проверено — сверяйтесь с packaging/README.md репозитория)

Команды — в разделе Linux файла [`SKILL.md`](SKILL.md): сборка OCCT 7.9.3 в `$HOME/occt`, клонирование
ветки, `cargo build --release --bin qymcad --bin qymcad-mcp`, а при запуске —
`LD_LIBRARY_PATH=$HOME/occt/lib`.

### Регистрация MCP-сервера

- **Claude Code:** `claude mcp add --scope user qymcad -- <путь к qymcad-mcp>` (на Linux добавьте
  `-e LD_LIBRARY_PATH=$HOME/occt/lib`). Проверка: `claude mcp get qymcad` показывает `Connected`.
- **Claude Desktop:** добавьте в `claude_desktop_config.json` (на Windows — `%APPDATA%\Claude\`) и
  перезапустите приложение:
  ```json
  { "mcpServers": { "qymcad": { "command": "C:\\Users\\<you>\\AppData\\Local\\Programs\\QymCAD-assistant\\qymcad-mcp.exe" } } }
  ```

Инструменты появляются только в **новых** сессиях.

### Включение живого режима

Запустите QymCAD, собранный из ветки (`qymcad.exe` в папке установки), и поставьте галочку
*Настройки → Общие → Разрешить ИИ-ассистенту работать в этом окне*. Окно запишет файл-дверь
(`assistant.json`: порт и токен) в свою папку данных (`%APPDATA%\qymis\qymcad\data`,
`~/.local/share/qymcad`), и сервер найдёт его сам. `describe_document` отвечает `"where": "window"`,
когда подключён к окну, и `"file"` — когда работает без окна.

## 2. Моделирование

Единицы — миллиметры и градусы. Чертёж в дюймах — умножайте на 25,4.

Порядок, который работает:

1. `describe_document` — понять, где вы и что уже есть.
2. Прочитать чертёж **до** того, как что-то рисовать. Выписать все размеры и решить, на каких гранях
   стоит каждый элемент. Неуказанные размеры — промерить по чертежу пропорционально известным и сказать,
   что принято.
3. Призматическую деталь строить из профиля сбоку: один `sketch` с замкнутой `polyline` на `XZ`
   (x — вдоль длины, y — высота), затем `extrude` на ширину. Эскиз на XZ выдавливается в сторону −Y.
4. После каждого шага, который меняет форму, — `screenshot` с `"view": "iso"` и **сравнение с чертежом**:
   где ступени, рёбра, отверстия. Числа говорят, что построено; картинка — то ли это. Изометрия по
   умолчанию смотрит из +X −Y +Z: X идёт вправо-вниз, Y — вправо-вверх, как на обычном изометрическом
   чертеже.
5. Грани и рёбра выбирать по `describe_body`: там центры, нормали, концы и радиусы; выбирать по геометрии
   (например, нормаль `[0,0,1]` и самый высокий центр — верхняя грань). Номера не угадывать.
6. Сквозные отверстия: `sketch` с окружностями на `XY`, затем `extrude` с `operation: "cut"`,
   `direction: "both"`, `through: true`, `body: <id>`. Окружность внутри замкнутого контура становится
   отверстием этого контура.
7. Шаг вышел неправильно — `undo` (можно с `count`) и сделать заново. Не строить поверх ошибки.
8. Сверять объём с ручным расчётом, когда форма достаточно простая.
9. Размеры, которые человек может захотеть поменять, вести параметрами: `set_parameter`, затем
   `set_dimension` (`feature`, `key`, например `height`).

Что полезно знать о модели:

- Деталь — одно тело: каждое `extrude` с `operation: "add"` и каждый `primitive` объединяются с телом детали.
- Сквозной вырез оставляет куски как несколько тел одной детали.
- Тело, поглощённое следующей операцией (скругление, вырез, булева операция), больше не принимает операций;
  работайте с id из последнего ответа.
- В окне `new_document` и `open_document` отклоняются: документ принадлежит человеку — попросите его открыть
  или создать документ. `save_document` там требует `path` и пишет копию.

## 3. Если что-то не так

- `"where": "file"`, хотя QymCAD открыт: галочка выключена, или окно из готового пакета (без живого режима),
  или остался старый `assistant.json` от убитого окна — перезапустите QymCAD.
- Сервер не запускается: нет DLL OCCT / `LD_LIBRARY_PATH`.
- В ответе есть `failed`: прочитайте код причины, `undo`, поменяйте входные данные.
- `screenshot` отклонён: окно не слушает.
